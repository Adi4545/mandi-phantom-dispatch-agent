# Implementation Complexity & Conceptual Simplicity Analysis (Revision v8)

This project demonstrates that an operational market dispatch safeguard does **not** require deep neural architectures or opaque parameter search when arrival missing-quote geometry dominates prediction variance (consistent with $1/N$ heuristic robustness in DeMiguel et al. 2009 and Gigerenzer & Gaissmaier 2011).

## 1. Algorithmic Simplicity Profile (`4.3/5` -> `1.6/5` -> `1.2/5`)
- **Zero-Tuned-Parameter Operational Rules (`m = 0`):** Built from `9` fixed structural choices (incl. `z = 1.0`, algebraic identity `p_dow * G_1SD - F == p_dow*(G_1SD - F) + (1 - p_dow)*(-1.0*F)` sunk freight, not literal `0`), `Safe_EV_Sunk_m0`, `Safe_EV_Phys_m0`, and `RT_2F_Min_m0` evaluate candidate corridor distances (`F_road = 35.0 + 0.45 * h_s * road_km`) and strictly prior reporting frequencies (`rep28`, `p_dow`) and volatility (`cv28`, `0.21%` sparse fallback on `77` episodes when `cnt28 < 2`) in sub-millisecond arithmetic. Note that argmax corridor selection still operates in additive INR units (`p_dow * G_1SD - F_road`); switching to ratio argmax changes `5,113` (`14.03%`) dispatches (`v7_exp4`).
- **Why Learned & OR Alternatives Were Evaluated Honestly (`v7_exp4` Honest Candidate C Synthesis):** Pre-registered Stage I hypothesis `H2` (`PREREG_A10.md`) tested a learned `HistGradientBoostingRegressor` ranking pipeline (`4.3/5`), which proved inconclusive (`+₹6.13/qtl`, Holm `p = 0.2699`). We explicitly retire any claim that zero-parameter rules beat all ML or that `safe_ev_feat` boosts `17m` ML: in `v7_exp4` (after purging `939` overlapping validation episodes), earlier ML/OR lags reflected `5m` off-season starvation (`ML_Ridge_EV_m0` `85.00%` `Mean ₹467.15` `cond_ES10 −₹542.58`; `ML_HGBR_EV_TV_age13_m0 −₹543.57`; `ML_HGBR_RiskAverse_L500 −₹537.57`), quadratic $\text{INR}^2$ penalties (`OR_Vargas_MeanVar_g0002 −₹511.42`), and homoscedastic CQR (`0` switches).
