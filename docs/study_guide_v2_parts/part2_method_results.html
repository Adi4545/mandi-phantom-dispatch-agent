Part 2: Zero-Tuned-Parameter Dispatch Rules, Experiments, 171-Mkt / ERA5 & Break-Even

This project demonstrates that an operational market dispatch safeguard does not require deep neural architectures or opaque parameter search when arrival missing-quote geometry dominates prediction variance (consistent with 1/N heuristic robustness in DeMiguel et al. 2009 and Gigerenzer & Gaissmaier 2011).

  • Zero-Tuned-Parameter Operational Rules (m = 0): Once candidate corridor distances (F_road = 35.0 + 0.45 * h_s * road_km) and strictly prior reporting frequencies (rep28, p_dow) and volatility (cv28, 0.21% sparse fallback on 77 episodes when cnt28 < 2) are read, Safe_EV_Sunk_m0, Safe_EV_Phys_m0, and RT_2F_Min_m0 evaluate each menu in sub-millisecond arithmetic. Note that argmax corridor selection still operates in additive INR units (p_dow * G_1SD - F_road); switching to ratio argmax changes 5,113 (14.03%) dispatches (v7_exp4).
  • Why Learned & OR Alternatives Were Evaluated Honestly (v7_exp4): Pre-registered Stage I hypothesis H2 (PREREG_A10.md) tested a learned HistGradientBoostingRegressor ranking pipeline (4.3/5), which proved inconclusive (+₹6.13/qtl, Holm p = 0.2699). 3.3 Equal-Menu Baselines, Heuristics, and Zero-Tuned-Parameter Lower-Bound Rules

On identical Top-5 candidates (lag_spread > 100, max 1 pick, abstention 0), all equal-age (1..3d) comparators match val_171 dispatch (70.43%): B1_lagged_screen (1 free param, age 1..7, 100%), B2_age_matched (G - F > ₹200, 1 param), B_simple_activity_matched (rep14 >= 0.50, ₹168.46, 2 params), MG_T1_T2_matched (ML-stripped rep14 >= 0.50 & dow8 >= 0.35, ₹133.03, 4 params; distinct from intact conformal MG_T1..T4 in v7_exp4), and RR_Abstain_matched (k*=5.0, m*=₹5.40, 2 params).

Locked in PREREG_A18.md (S > 0), we examine three lower-bound triage heuristics with zero validation-tuned parameters (built from 7 fixed structural choices: age 1..3, Laplace pdow = (k+1)/10, 28d window, z=1.0 cv28 haircut, 0.05 cnt28<2 fallback [checked against cnt28<5], sunk F/2F/1.5F, threshold 0):

  • Safe_EV_Sunk_m0 (Product Score): Using G1SD(c, t) = Pdest,lag(1 - cv28)(1 - τfee) - Porig,lag, select argmaxc SSafe-EV(c,t) = pdow G1SD - Froad > 0 (whose acceptance gate S > 0 ⇔ G1SD/Froad > 1/pdow; the argmax objective is non-invariant under ratio transformation, causing 5,113 candidate switches [14.03%] in v7_exp4). Explicitly, SSafe-EV is a conservative lower-bound score assuming 0 return payoff on failure (not a literal expected value).
  • Safe_EV_Phys_m0: pdow(G1SD - F) - (1 - pdow) 1.5 F > 0 (explicit return cost lower bound).
  • RT_2F_Min_m0 (0 params, NO cv28, NO spoil): Using plain G and pmin = min(rep28, pdow), dispatch if pmin G - 2F > 0.

Worked Example 3 (Pocket Arithmetic): On MP Tomato (G = +₹470, cv28 = 0.15, G1SD = +₹174.50, F = ₹125): steady yard (dow8 = 0.90, p_min = 0.85) yields Safe_EV = +₹32.05 > 0 and RT_2F = +₹149.50 > 0 (DISPATCH); Sunday yard (dow8 = 0.20, p_min = 0.20) gets B2 = +₹345 blindly yet yields Safe_EV = −₹90.10 and RT_2F = −₹156.00 (STAY HOME).

3.4 Fractional ES10, Conditional cond_ES10, and Small-Cluster Inference

Following coherent expected shortfall (Rockafellar & Uryasev, 2000), we report both unconditional ES10 (including 0 on abstention — rewarding selectivity mechanically via zero-padding) and conditional cond_ES10 evaluated solely across dispatched trips (equalizing risk on committed capital) with fractional interpolation m = 0.10n = k + f:

ES10(x) = 1m(∑i=1k x(i) + f · x(k+1))

Worked Example 4 (Fractional ES10): On {1, 2, …, 11}, m = 1.1 (k = 1, f = 0.1), giving (1 + 0.1 × 2)/1.1 ≈ 1.09.

Locked confirmatory inference evaluates the PREREG_A18.md 4-test family at exact R = 2,000 paired two-way cluster bootstraps (Phipson & Smyth, 2010; Holm, 1979) (166 State|Market × 23 fortnights), supplemented by Cameron–Gelbach–Miller (CGM) G* t-tests, studentized t bootstraps, Webb 6-point wild tests (B = 12 4w blocks & HP B = 12), and joint val+test threshold propagation (v7_exp5).
