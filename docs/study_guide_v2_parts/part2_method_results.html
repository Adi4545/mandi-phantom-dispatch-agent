3.3 Equal-Menu Baselines, 9 Structural Choices, and Algebraic Risk Identity

On identical Top-5 candidates (lag_spread > 100, max 1 pick, abstention 0), all equal-age (1..3d) comparators match val_171 dispatch (70.43%): B1_lagged_screen (1 free param, age 1..7, 100%), B2_age_matched (G - F > ₹200, 1 param), B_simple_activity_matched (rep14 >= 0.50, ₹168.46, 2 params), MG_T1_T2_matched (ML-stripped rep14 >= 0.50 & dow8 >= 0.35, ₹133.03, 4 params; distinct from heteroscedastic Split-CQR MG_T1..T4 in v7_exp4), and RR_Abstain_matched (k*=5.0, m*=₹5.40, 2 params).

Locked in PREREG_A18.md (S > 0), the tuning-free rules rest on nine fixed structural design choices (age 1..3, Top-5 cutoff, lag_spread > 100, Laplace pdow = (k+1)/10, 28d window, z = 1.0 cv28 haircut, 0.05 cnt28 < 2 fallback [checked against cnt28 < 5 / cv28 == 0], sunk F/1.5F/2F cost weights, threshold 0):

  • Safe_EV_Sunk_m0: With G1SD(c, t) = Pdest,lag(1 - cv28)(1 - τfee) - Porig,lag, score argmaxc SSafe-EV(c,t) = pdow G1SD - Froad > 0. Exact algebraic identity:
pdow G1SD - Froad ≡ pdow(G1SD - Froad) + (1 - pdow)(-1.0 Froad)

proving Safe_EV_Sunk_m0 prices -1.0 * F_road sunk return freight on silent yards (rather than literal zero), while Safe_EV_Phys_m0 replaces -1.0 * F_road with -1.5 * F_road, differing purely by 0.5(1 - pdow)Froad. Switching from additive INR argmax to ratio argmax (G1SD/Froad - 1/pdow) switches 5,113 (14.03%) test destinations (Mean ₹437.28, ES10 −₹329.26, v7_exp4).

  • RT_2F_Min_m0 (0 tuned params, NO cv28, NO spoil): Using plain G and pmin = min(rep28, pdow), dispatch if pmin G - 2F > 0.
  • ScaleInv_Safe_EV_24tau & 2×2 Orthogonal Components (v7_exp4–v7_exp5): To isolate cv28 vs p_dow, we decompose into Ortho_Pure_cv28_only (G1SD - Froad > 0) and Ortho_Pure_pdow_only (pdow G - Froad > 0). When spreads dwarf freight (F / G1SD < 0.10, occurring on 79.52% of HP apple Safe_EV dispatches), pdow G1SD - Froad > 0 suffers scale non-invariance because proportional origin spoilage Porig · s24τ is omitted. Adding full transit-horizon spoilage and 1.5 F yields scale-invariant ScaleInv_Safe_EV_24tau (pdow(G1SD,fix - F - Pdest s24τ) - (1-pdow)(1.5F + Porig s24τ) > 0).

Worked Example 3 (Pocket Arithmetic & Algebraic Identity): On MP Tomato (G = +₹470, cv28 = 0.15, G1SD = +₹174.50, F = ₹125): steady yard (dow8 = 0.90, p_min = 0.85) yields Safe_EV = +₹32.05 > 0 and RT_2F = +₹149.50 > 0 (DISPATCH); Sunday yard (dow8 = 0.20, p_min = 0.20) gets B2 = +₹345 blindly yet yields Safe_EV = −₹90.10 and RT_2F = −₹156.00 (ABSTAIN). Equivalently, 0.90(174.50 - 125) + 0.10(-125) = +₹32.05.

3.4 Fractional ES10, Conditional cond_ES10, and Finite-Sample CGM G* Inference

Following coherent expected shortfall (Rockafellar & Uryasev, 2000), we report both unconditional ES10 (including 0 on abstention — rewarding selectivity mechanically; in Uttar Pradesh where episode loss rate is 7.28% < 10%, unconditional q10 = 0 creates a point-mass zero atom absent in cond_ES10) and conditional cond_ES10 over dispatched trips via fractional interpolation m = 0.10n = k + f:

ES10(x) = 1m(∑i=1k x(i) + f · x(k+1))

Worked Example 4 (Fractional ES10): On {1, 2, …, 11}, m = 1.1 (k = 1, f = 0.1), giving (1 + 0.1 × 2)/1.1 ≈ 1.09.

Specification-locked exploratory inference evaluates PREREG_A18.md (R = 2,000 paired two-way cluster bootstraps (Phipson & Smyth, 2010; Holm, 1979), 166 State|Market × 23 fortnights), supplemented in Revision v8 (stats_utils.py, v7_exp_summary.json) by finite-sample G/(G-1)-scaled Cameron–Gelbach–Miller (CGM) G* t-tests, studentized t bootstraps, 1-way block-only Webb6 wild tests (p_wild_webb6_1w_block_only, B = 12), and joint val+test threshold propagation.
