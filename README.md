# MandiGuard

MandiGuard evaluates dispatch decisions using historical Indian mandi price reports. On 69,526 shortlisted episodes, its modeled gain over a stale-price heuristic was ₹102.78 per quintal. The difference against the fresh-price and road-cost comparator was ₹6.13, with a 95% bootstrap interval from −₹17.02 to +₹25.02.

Start with the [revised research manuscript](paper/manuscript.md), [correction record and replay instructions](final/CORRECTIONS.md), and [independent review](final/reviews/adversarial-review.md). The original experiments and teaching materials preserve the project's history. Use the correction record for tail losses, selected-route diagnostics and decision-weather interpretation. Observed farmer income and operational dispatch-time forecast availability remain unverified.

The [exploratory agent study](final/STAGE3_AGENT_STUDY.md) compares routing a limited forecast budget with reviewing every B2 proposal, on both the main and graded-apple panels.
